On-board schedule

Time-tagged commands planned on the ground for the on-board scheduler. Entries can be planned at any time, also during LOS.

Sync reads the on-board schedule back (if supported), reconciles the entries with it, then inserts, deletes or replaces on-board entries so that the on-board schedule matches the ground plan. Plan sync only shows what a sync would do. Read back only reconciles.

The state of each entry is updated from telemetry, including telemetry recorded on board during LOS and dumped afterwards.
